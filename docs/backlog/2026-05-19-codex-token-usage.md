# Codex token 消耗联动

## 背景

用户希望桌宠加强与 Codex 的联动，其中 token 消耗是有价值的元数据，但当前阶段暂不实现，先记录为后续需求。

## 描述

后续可在只读取 Codex 本地元数据的前提下，展示当前线程或当前工作周期的 token 消耗、预算使用比例和高消耗提醒。该能力必须保持隐私边界清晰：不读取 session 正文、不解析用户消息、不解析模型回复。

## 验收标准

- 能从 Codex 元数据中读取 token 相关字段或聚合指标。
- 能在桌宠状态条、右键菜单或后续面板中展示 token 消耗。
- 高 token 消耗时能触发克制的宠物行为反馈。
- 明确记录读取的数据来源和隐私边界。
- 不读取 rollout/session JSONL 正文。

## 暂不做

- 当前 Codex 元数据联动 MVP 不包含 token 消耗展示。
- 不做语音播报 token。
- 不接云端统计或遥测。
