# 桌宠语音反馈

## 背景

用户提出不同交互可以配合合适音色的语音反馈。该方向能增强陪伴感，但涉及打扰度、系统音量、音色选择、开关配置和隐私说明，当前阶段暂不实现。

## 描述

后续可为高价值事件增加低频语音反馈，例如连续工作提醒、等待用户确认、任务完成、验证失败或长时间无进展。语音反馈应默认可关闭，避免在工作场景中造成干扰。

## 验收标准

- 语音默认关闭或有明确开关。
- 支持选择 macOS 系统可用音色或预设音色。
- 只在高价值事件触发，不为普通 ambient 动作发声。
- 有冷却机制，避免连续播报。
- 文档说明语音内容来源和隐私边界。

## 暂不做

- 当前 Codex 元数据联动 MVP 不包含语音。
- 不接第三方 TTS 服务。
- 不读取对话正文生成语音内容。
