# 足球宝贝候选形象 v1

本目录保存已确认外观的候选参考素材，尚未接入 App runtime，也不会覆盖现有 `Lingxi OL`。

## 角色锚点

- 成年东亚女性，冷调白皙肤色，长卷发和圆框眼镜。
- 红白黑 V 领短款运动背心，露出腰腹。
- 红白不对称百褶裙裤，裸腿。
- 白色纤薄低帮运动鞋，薄底、无长袜。
- 足球保持正常比例；所有素材使用可抠除的绿幕背景。

## 排格处理

AI 生成的横条可能跨越理论格线。最终文件已使用下面的确定性命令按人物主连通域重新居中，避免切格后混入相邻人物碎片：

```bash
python3 scripts/normalize-chroma-strip.py <input> <output> --columns <格数>
```
